# Visuels Manoo

Branche d'hebergement des fichiers publics utilises pour la publication automatisee
sur Instagram et LinkedIn. Elle ne contient aucun code : `main` n'est pas touchee.

- `instagram/` : visuels 1080x1350, servis en direct a Meta.
- `calendrier.json` : le calendrier editorial, lu par la publication automatique.

Pour changer un visuel, remplacer le fichier au meme nom : l'URL publique ne change pas.
